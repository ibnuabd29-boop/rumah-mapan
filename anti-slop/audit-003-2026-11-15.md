# Audit antislop 003

Tanggal: 2026-11-15

## Temuan

1. **HIGH, akses fitur dashboard pengguna diblokir untuk admin (R-26).** Halaman Perasaan, Catatan, Masa depan, Materi, Laporan, dan fungsi notifikasi memeriksa `is_admin` lalu menolak pemakaian; kebijakan RLS dan RPC juga menolak tulis admin, termasuk pada rumah yang admin ikuti sendiri. Agar admin dapat memakai fitur sebagai pengguna tanpa membuka data keluarga lain, perubahan perlu membatasi akses pada rumah tempat akun admin terdaftar dan tetap menjaga batas privasi data anggota.
